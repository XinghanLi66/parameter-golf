# Proposal: Agentic Research Coding for Scientific Reproduction

## Idea

I want to study whether a coding agent can more reliably reproduce small-scale research claims when it is forced to:

1. translate a vague idea into a measurable hypothesis
2. create a minimal baseline first
3. run at least one executable check before proposing larger experiments
4. keep an explicit experiment ledger

## Desired output

- a concrete research plan
- runnable code and scripts
- at least one baseline experiment
- suggestions for the next ablations

## Resource notes

- GPU may be used when helpful, but CPU baselines are also acceptable
- if GPU is used, keep the command reproducible and logged
